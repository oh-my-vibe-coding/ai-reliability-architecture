# 复习系统 · 如何使用

> [← 返回目录](../README.md)

## 2. 两种复习方式

### 方式 A · Anki（推荐给重度学习者）
1. 下载 [Anki](https://apps.ankiweb.net/) （免费）
2. `File → Import` 导入 `anki-import.csv`
3. 每天可从 10-20 分钟起步，按实际负担调整
4. 按所选调度设置安排间隔，依据实际负担调整新卡与复习量

本版包含 **140 张唯一题面**，Markdown 与 CSV 逐卡对应。已有 v1.15.7 牌组可先看[题面迁移表](v1.16.0-题面迁移.csv)，再检查导入变更：首字段改名可能形成新笔记，应更新原笔记以保留进度。10-17 与 10-18 的迁移说明见[维护记录](../维护/2026-10-17-三层维护记录.md)和[发布审查](../维护/2026-10-18-发布审查.md)。

### 方式 B · 手动快读（推荐给轻度学习者）
按**"间隔递增"**手动过 `核心概念卡.md`：

- 第 1 天：学完新 Unit 后通读
- 第 3 天：合上答案自测
- 第 7 天：再自测一次
- 第 14 天
- 第 30 天
- 之后每月一次

**操作技巧**：建一个简单 markdown 表跟踪"今天该过哪些卡"——

```markdown
| 卡片范围 | 上次读 | 下次读 |
|---|---|---|
| 引章卡（Q1-Q6） | 2026-05-15 | 2026-05-22 |
| 第 4-5 章卡 | 2026-05-19 | 2026-05-22 |
```

**或者**：直接把 `anki-import.csv` 喂给任何 SR 软件（Anki Desktop / AnkiDroid / Mochi / RemNote / Apple Shortcuts + ChatGPT），让算法替你排。**强烈不推荐用 Excel 排间隔**——会忘。

若旧问题已经无法独立解释或重做，优先回到对应材料与实验，不以连续打卡证明掌握。

## 3. Active Recall 提问的用法

和 SR 卡不同——这些是**开放式问题**，用来练"**自己把东西讲清楚**"。

建议用法：

1. **每学完一章，拿其中 2-3 道题**
2. **合上书，口头或书面回答**
3. 回答完**再翻书对比**
4. 记下"没想到 / 讲错了"的点
5. 可以贴给 AI：**"挑我这个回答的漏洞"**（但别让它给答案）

---

## 4. Bloom 分级标注的用法

本书的主要练习都标了 Bloom 六级之一：

```text
记忆 → 理解 → 应用 → 分析 → 综合 → 评估
```

- 如果你发现自己**一直停在"理解"**（看懂但不会用）——该做更多 **应用 / 分析** 类练习
- 如果你**跳过了"应用"直接做"综合"**——会产出"看起来完整但漏洞百出"的方案
- 详细见 [Bloom分级说明](Bloom分级说明.md)

## 5. 复习节奏推荐

| 时间 | 动作 | 预计耗时 |
|---|---|---|
| 学完一个 Unit | 通读当 Unit 对应的 SR 卡 | 15 分钟 |
| 学完一个 Unit | 回答 2-3 道 Active Recall | 20-30 分钟 |
| 每周 | Anki 新卡 + 复习（自动调度）| 10-15 分钟/天 |
| 每月末 | 回答 [附录 A · 自检表](../附录/A-每月自检表.md) + 抽 5 张老卡自测 | 20 分钟 |

---

## 6. 为什么这套东西重要

| 学习科学原理 | 本系统的应用 |
|---|---|
| **Spaced Repetition**（Ebbinghaus）| 对抗遗忘曲线，按间隔复习 |
| **Active Recall / Testing Effect** | 用主动提取检查回忆与理解，再核对错误 |
| **Elaboration** | Active Recall 题强制你"关联已有知识" |
| **Bloom's Taxonomy** | 让你看到自己的学习停留在哪一层，避免"看似懂了" |
| **Metacognition** | 暴露"没想到"的盲区，是最重要的学习信号 |

---

## 7. 给 SRE 的一句话提醒

> [!IMPORTANT]
> 复习用于发现遗忘与理解缺口。间隔、题目和时长可调整；用具体的延迟重做、解释与新情境表现检验效果，不套用统一遗忘百分比。
