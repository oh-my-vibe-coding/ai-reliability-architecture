# 更新模板 · 如何规范记录一次更新

> [← 维护系统](README.md)

一次更新要让继任者看懂：原来写了什么，为什么要改，证据支持到哪里，哪些配套已经同步。事实更新可简写；涉及[工作范式或核心论断](范式与理念审查.md)时，应保留反例、适用范围和修订理由。

---

## 1 · 变化与修订记录

复制到本轮维护记录，或在 Unreleased 中链接到对应记录：

```markdown
### 变化 ID / 标题

- 对象：事实与实现 / 工作范式 / 核心论断与理念（可多选）
- 原句及定义源：文件、章节、原文；有关联时填论断 ID
- 原主张类型：事实或因果判断 / 工程建议 / 价值与责任选择
- 原有前提：任务、数据、模型、工具、成本、组织或风险条件
- 候选变化：具体改变了什么，不只填写新术语
- 来源：原始材料、发布日期、核验日期与可访问位置
- 来源独立性：是否转引同一材料；哪些只有厂商声明
- 证据：实验或记录位置、环境、版本、样本、标准与结果
- 反例与替代解释：最强反方观点，已核实和仍未知的部分
- 外推限制：证据覆盖什么，不能证明什么
- 决定：保留 / 待验证 / 限定 / 改写 / 撤回
- 决定理由及新表述：为什么；新结论的适用边界
- 影响：读者应改变哪项决定、工作流、练习或验收
- 同步范围：正文、代码、模板、路线、复习卡、Anki、导航等
- 验证：已执行检查及结果；未执行项单列
- 负责人 / 复核者：实际人员或角色，不虚构独立 review
- 后续动作：未知、期限或回看条件，以及何时再改判断
```

不是每条勘误都需要长报告。纯死链或价格更新可以使用精简记录：旧值 / 原地址、新值 / 新地址、官方来源、日期、定义源和派生同步位置。不能把复杂方法变化压缩成"新版本发布，已更新"。

## 2 · Unreleased 与发布条目

未发布的编辑和待研究线索分开记录：

```markdown
## 未发布（Unreleased）

### 已完成修订
- [具体文件、原问题、新行为或新表述、证据记录]

### 待验证 / 待处理
- [线索、潜在影响、缺失证据、负责人及回看条件]
```

决定发布后，按[版本约定](README.md)整理条目，不按月、季度或年度自动选版本：

```markdown
## vX.Y.Z — YYYY-MM-DD

### 事实与实现
- [原信息 → 新信息，来源、快照及兼容影响]

### 工作范式与方法
- [原流程 → 新流程，适用任务、证据与代价]

### 核心论断与理念
- [原主张 → 新主张，关键前提、反例及修订理由]

### 读者需要调整什么
- [旧实践如何迁移，哪些建议已限定或撤回]

### 验证与遗留
- [实际完成的检查；未核实来源、未执行实验及行动项]
```

没有涉及的类别可以省略。保留或待验证的结论也应有依据，但不必为它们单独发布新版本。

---

## 3 · 正文与元数据

- 先修改定义源，再检查引用它的段落、表格、练习和复习卡。
- 正文真实变化时才更新该文件的 `updated`，不因检查过就刷新日期。
- 快照值附来源与日期；经验和建议附条件，核心论断附理由与复评信号。
- 标题、文件路径或结构变化时，检查导航、内部链接和旧锚点，必要时提供兼容入口。
- 已发布版本统一同步主 README、维护 README、CHANGELOG 和站点元数据；未发布编辑不单独 bump。

修改核心论断时，前言、引章、结语和学习路线也可能需要检查。避免正文已经限定，而复习题仍要求读者背诵旧的绝对结论。

## 4 · 提交与审查说明

提交说明按实际变更写，不强制套用维护周期：

```text
修订：限定 [原主张] 在 [范围] 内的适用条件

原因：[新证据或原有论证缺口]
影响：[正文与配套范围，读者需要调整的实践]
验证：[已执行检查]
遗留：[未知与后续动作]
```

提交前核对工作区差异，只纳入本次应提交的文件。涉及主线或核心主张的变更，将证据和反方意见交给复核者；个人维护时说明独立审查的限制。一次提交的组织方式应便于理解和撤回，不由版本标签机械决定。

---

## 5 · 同步与验收清单

- [ ] 定义源、原句、变化类型和证据可追踪。
- [ ] 区分事实 / 因果、工程建议、价值选择，没有把一种证明方式套给所有主张。
- [ ] 反例、核验限制和不能外推的部分已写清。
- [ ] 明确作出保留、待验证、限定、改写或撤回的决定。
- [ ] 方法更新落实到实际工作流；理念更新落实到论证和适用边界。
- [ ] 正文、案例、代码、模板、训练路线和验收完成必要同步。
- [ ] 核心概念卡与 Anki 同步，相关 Active Recall 题不再强化旧结论。
- [ ] 相关链接、导航、算例和构建通过；未执行的实验未写成通过。
- [ ] Unreleased / 发布记录区分已完成修订、观察与待办。
- [ ] 强建议有可观察的复评条件，见[样式指南](../样式指南.md)。
