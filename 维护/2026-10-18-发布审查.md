# v1.16.0 · 发布前审查

> [← 维护系统](README.md)  ·  [CHANGELOG](CHANGELOG.md)

本次审查覆盖 v1.15.7 之后的全部待提交修改，包括第 1—20 章精修、Capstone 与 Unit 配套修订、三层维护手册和 10-17 维护执行结果。按用户授权在修复并验证后提交、推送和发布 v1.16.0。

## 1 · 审查结论与版本选择

主线的论证、案例和行文已收敛到可检查的工程条件：任务结果、证据、授权、状态、质量、成本和恢复。未发现需要撤回本书阅读主线的问题；发布前发现的学习资产同步及缓存算例问题已修复。

新增工作范式与核心论断审查方法及配套流程，适合 minor；不因为字数变化或维护日期决定版本。S/M/L、成熟度等本书自定标签已明确适用范围，旧标签应按新判据重评，不能直接当作质量证明。

这是同一维护会话中的再次审查，不是第二位维护者的独立 review。厂商和研究材料的局限仍以[10-17 维护记录](2026-10-17-三层维护记录.md)为准。

## 2 · 发现及修复

| 级别 | 问题与影响 | 修复 |
|---|---|---|
| P1 | 题库仍要求论证正文已撤回的全量重传、固定记忆比例、统一阈值与必要流程 | 改写 Active Recall 中 27 个问题，要求交代条件、比较证据和反例 |
| P1 | Markdown 有 140 张卡，CSV 只有 134 张；旧容量答案仍用 QPS，且部分答案不同 | 补齐 6 张部署线卡，逐题校验全部 140 张，不再只检查改过的条目 |
| P1 | 缓存专题开头把演算读价当全系当前价，并把新处理 token 比例推成计算与总费用倍数 | 写明假设、有效期及命中次数，复算输入费；撤去未经演算的总账单 8 倍结论 |
| P2 | 概念卡继续强化无条件的瓶颈、污染判断、tokenizer 比例与内部表示推断 | 收紧相关答案；术语表区分工作流执行预算与模型内部思考 |
| P2 | 主书参考架构单图缩放后文字过小，可靠性对照公式挤入页边 | 拆分请求与运行控制两图，将三种设计的公式分行，重建 PDF 并复查 |
| P2 | 多张题面已改名，直接导入可能产生新 Anki 笔记并丢失对应关系 | 提供 v1.15.7 → v1.16.0 的 43 条题面映射；6 张部署线卡作为新增卡 |

定位文件：[题库](../复习/Active-Recall题库.md)、[概念卡](../复习/核心概念卡.md)、[Anki CSV](../复习/anki-import.csv)、[缓存专题](../深入/02-Prompt-Caching原理.md)、[术语表](../附录/C-术语表.md)。

迁移时先按[题面映射](../复习/v1.16.0-题面迁移.csv)更新原笔记，再导入更新答案，以保留学习进度。该表只映射本仓库 v1.15.7 的题面，不自动操作用户牌组；其他版本需自行比对。

## 3 · 复核方法

- 内容：核对主线的因果与概率前提、服务测量边界、单位、责任及恢复条件，检查方法变更是否传递到题库、卡片与训练材料。
- 数据：快变事实保留 10-17 读取日期及原始来源，不在发布时伪装成 10-18 全量重采。
- 数学：重算串联与 gate 示例、分层抽样、错误预算、单位有效任务成本与缓存费用；不把教学数字当硬件或模型实测。
- 构建：站点使用仓库 MkDocs 配置，主书 PDF 使用现有 Pandoc / XeLaTeX 与 Mermaid 预处理；版本和日期统一读取已发布元数据。
- 边界：没有付费模型调用、GPU 压测、生产实验、论文复现或学习效果实验。

## 4 · 发布验证

- `git diff --check`：通过；实际修改文件的元数据、单 H1、标题深度、围栏和表格列数检查通过。
- MkDocs 严格构建：通过；全书 1,895 处相对文档链接及目标锚点检查通过，修复了代码指南中一处旧 Pattern 4 链接。
- 现有锚点测试 5 项、PDF 预处理测试 3 项：通过。
- Markdown / CSV：140 张唯一题面，题面与去除排版标记的答案逐项一致，CSV 每行 3 字段；43 条旧题面映射均指向有效的新题面。
- 数学复算：串联与一次重试 gate、分层抽样、错误预算、缓存输入费用、单位有效任务成本均与正文一致。
- PDF：33 份主书输入、18 张 Mermaid 图、213 页。检查封面日期、页眉版本、全部主线章节与元数据隔离；最终逐页生成缩略图并目视检查，详细抽查公式、参考架构、RACI、预算、项目表和代码排版，修正后未见裁切或重叠。
- 本机 BasicTeX 补齐中文和排版依赖后完成构建。仍有 3 条 CTeX 对 LaTeX 内核版本的兼容提示，未出现缺字消息；这是构建环境提示，已保留在本轮日志中，不宣称编译零告警。
- 发布附件按最终源文件构建，PDF、静态站、Anki 与题面迁移 CSV 以 SHA256SUMS 提供校验。

## 5 · 遗留与交付范围

Arena、MTEB、SWE-bench 当前排名仍有取数缺口，Moonshot 当前价未取得正文；部分历史模型与框架表格尚需专项核验。它们已经标明日期或缺口，不会因本次发布被宣称为当前事实。

主书 PDF 包含主线与选定总览和附录，全部深入专题、练习详情、复习资产与维护记录随完整静态站提供。GitHub Release 附 PDF、站点压缩包、Anki 与题面迁移 CSV 和 SHA256SUMS；Pages 由推送 main 的既有工作流构建。
