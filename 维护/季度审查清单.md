# 季度审查清单

> [← 维护系统](README.md)

季度审查同时处理**事实与实现、工作范式、核心论断与理念**。重点检查高影响变化是否改变读者的实践与判断；可以得出暂不修改的结论，不用新增章节或修改数量证明审查有效。

---

## 1 · 确定范围与工时

约 2 小时可以作为一轮分诊和重点审查的起步安排。资料核验、复现实验、论证改写和跨章同步可能需要更多时间，应单列任务、负责人和期限。

- [ ] 读取[月度记录](月度更新清单.md)、[Unreleased](CHANGELOG.md#未发布unreleased)和[漂移度表](漂移度表.md)。
- [ ] 按读者影响、错误后果和证据缺口排序，不只按厂商发布热度排序。
- [ ] 从[核心论断台账](范式与理念审查.md)中选取主张复评，逐季覆盖其余主张；记录本次未审范围。
- [ ] 确认候选变化是事实、工作方法还是核心论断层面，允许同一项涉及多层。

已确认的危险建议、事实错误或关键前提失效，应及时处理，不等凑满一个季度的变更。

---

## 2 · 三条审查线

### A · 事实与实现

- [ ] 模型、API、价格、配额与退役条款是否仍有可核验来源？
- [ ] 工具、运行环境、数据与评估协议变化，是否使旧结果不可直接比较？
- [ ] 榜单、事故、法规和合同引用的日期与适用范围是否准确？
- [ ] 正文与代码、模板、复习卡和 Anki 是否仍一致？

沿用[月度清单](月度更新清单.md)的来源核验。没有取得新数据时保留历史日期并说明缺口，不能把推测填进快照。

### B · AI 工作范式

按[范式扫描维度](范式与理念审查.md)检查：

- [ ] 委托单位是否改变：局部问答、完整任务、持续运行分别怎样验收？
- [ ] 交互是否改变：异步交付、异常升级、多人协作是否需要新的观测与交接？
- [ ] 上下文与状态是否改变：记忆、检索、缓存和共享状态怎样保持来源、权限与时效？
- [ ] 执行方式是否改变：长任务、重试、检查点、取消与外部副作用如何恢复？
- [ ] 验证方式是否改变：模型、确定性检查和人工复核怎样分工，成本与漏判如何变化？
- [ ] 变化是否实际影响工作流，而非只换产品名称、术语或演示方式？

不默认单 Agent 要升级成多 Agent、短任务要变成长任务、人工审批要全部取消。比较选定场景的收益、失效和完整成本后，再修改推荐。

### C · 核心论断与理念

至少选一个影响较大的主张，按[六个复评问题](范式与理念审查.md)留下记录：

- [ ] 第 1—3 章关于任务委托、职责、学习和判断的主张，其前提与反例是否写清？
- [ ] 是否把一种经验、价值选择或组织安排写成普遍因果规律？
- [ ] 第 4—17 章的建议是否仍由当前任务、风险、验证与成本证据支持？
- [ ] 第 18—21 章的训练，是否仍检验目标能力，而非只检验当期工具使用？
- [ ] 反方证据是否被公平处理？需要限定、撤回或重建哪段论证？

"理念章节"的低变动标签不免除这条审查线。也不能因为某模型分数提高，就直接宣布关于学习或责任的主张失效。

---

## 3 · 选取证据，形成修订决定

对每个优先候选填写[更新模板](更新模板.md)：原句、前提、新证据、反例、核验限制、决定和影响范围。

| 核查结果 | 本轮处理 |
|---|---|
| 只有发布或演示信号 | 登记待验证，写明需要什么证据 |
| 证据只支持特定任务 | 限定推荐范围，保留其他场景的未知 |
| 原有表述有误 | 修订定义源，检查派生引用 |
| 工作方式或核心前提发生变化 | 修改方法与论证，补验证和迁移说明 |
| 原句仍有支持 | 记录保留理由与复评条件，可以不改正文 |

新章节不是唯一处理方式。优先检查能否删除过强建议、修正一个适用条件、替换失效练习或整合已有材料。确有未覆盖的重要问题时再扩写，按读者价值控制篇幅。

---

## 4 · 同步与验证

- [ ] 定义源、前言与章节结论是否一致，相关主张没有一处撤回、一处仍当定律？
- [ ] 案例、代码、模板、学习路线、练习与验收是否同步？
- [ ] 复习卡和 Anki 同步；必要时调整 Active Recall 题目。
- [ ] [内容路线图](内容路线图-v2.md)中的候选是否已被新证据支持、限定或否定？
- [ ] 漂移度及事件触发条件是否需要调整？
- [ ] 相关算例、链接、导航和构建是否通过？实验结果可复现吗？
- [ ] 明确区分文档检查、离线实验、目标环境验证和未执行工作。

---

## 5 · 记录与发布

先在 Unreleased 记录完成的修订和待验证项。版本按[维护总览](README.md)的实际影响选择，不按季度自动升级 minor；发生主线重构也不必等待年度。

发布说明应回答：过去的主张或方法是什么，为什么改变，现在适用于哪里，老读者需要调整什么，仍有什么未知。改写核心主张时，交由其他维护者复核；个人维护则明确核验方式与审查限制。

年度重审的候选也在此登记。只要一项变化足以改变全书主线，就应提出重审；不需要凑够三项，已经确认的错误也不留到年审才纠正。
