## Review 与发布检查

审查对象为本轮完整 diff、来源支持、跨章一致性、示例量纲、复习卡同步与阅读产物。审查发现并修复：

- OpenAI 新代际缓存写入不再零溢价；补断点、usage 与保留配置，保留网关逐项对账要求。
- Sonnet 前缀输入费用与 Haiku Batch 示例按当前价重算，去掉已经失效的自建必胜结论。
- 离线实例数改为 token 量除以时间与吞吐，不把 24h 目标当完成保证。
- PDF 脚本从 README 读取版本、补第 7 章、隔离章节 YAML 元数据以修复封面覆盖、同步页眉 / 日期、渲染 37 张 Mermaid 图，并转换在线链接；修复代码换行、数学符号缺字和超高图形。
- 阅读站保留原有锚点，并补 GitHub 风格中文锚点，以修复跨渲染器章节跳转。
- 修正 MoE 激活参数与权重显存的混淆、长上下文耗时线性外推，以及复习卡中 temperature 与 Lost in the Middle 的旧表述。

验证结果：

- 完整 diff 逐项审查完成，来源、旧快照边界、跨章引用与示例量纲已复核，无未处理的发布阻塞项。
- `mkdocs build --strict` 通过；章节链接与锚点检查无告警，版本页脚 / 默认版本同步为 v1.15.6。
- 5 项锚点回归测试、3 项 PDF 预处理测试通过；覆盖原有 URL、中文标题、重复标题、元数据隔离、代码块链接保留、图形去重与失败中止。
- Markdown 元数据 / 单一 H1（排除代码块）、Anki CSV 三列结构与三张修订卡同步、Decimal 成本复算、Shell 语法和 `git diff --check` 通过。
- 主书 PDF 含 33 份输入与 37 张图；检查封面、目录、第 7 章、密集表格、代码块和页眉，整书缩略页检查通过；最终构建无缺字、未解析引用与图形超高告警。

发布产物为主书 PDF、完整静态阅读站压缩包与 SHA-256 校验和；来源中的网络失败和未复核历史项保留在正文与 Unreleased，作为后续维护事项。
